# 后端

平台账号可选择 OpenCode 或 Pi；个人空间新建会话时也可选择。每个会话固定绑定创建时的后端，修改账号设置只影响新会话。平台 `/new` 使用账号当前选择，个人空间重置保留原后端；旧历史仍可查看。

本阶段不迁移已有会话上下文，也不接管另一后端正在执行的工具。

| 能力 | OpenCode | Pi 首版 |
| --- | --- | --- |
| 模型 | 原生提供方及自定义服务 | WebUI 配置的 OpenAI 兼容服务，必须指定模型 |
| 流式、工具、取消 | 支持 | 支持 |
| 排队 | queue / steer | queue |
| 平台提问、发送附件 | 支持 | 支持 |
| 工具目录按需加载 | 支持 | 支持 |
| MCP、浏览器、Skills | 支持 | 尚未接入 |
| 手动压缩、Agent 切换、权限规则 | 支持 | 尚未接入，工具默认允许 |
| 调试 | HTTP/SSE、工具、Token 与缓存 | 本轮用时、工具、Token 与缓存；不伪造 HTTP/SSE 计时 |

账号修改绑定模型后，同后端的未归档会话使用新模型；当前生成不打断。Pi 在下一条输入执行时应用模型变化。其他后端的旧会话保留自己的模型，可在会话设置中修改。

Pi 使用 `@earendil-works/pi-coding-agent` 1.6.0，原生会话保存在 `.ineffa/pi/sessions/`。它不读取外部 AGENTS.md、Skills 或扩展。共享模型配置仍保存在 OpenCode 配置文件中，Pi 读取兼容服务的地址、密钥和模型信息，不另建模型配置数据库。

Pi 的原生 JSONL 保存执行历史；`delivery.sqlite` 只用于输入接收、平台投递事件和原生消息 ID 对照。服务异常退出后，已接收但未开始的输入继续排队，执行中的输入停止并标明中断，不自动重跑可能已经产生副作用的工具。重新提交前先检查上次结果。

两种后端的导出文件保留各自原生格式，不能互相直接导入。配置导入导出包含账号后端选择和共享模型配置，不包含会话历史。
