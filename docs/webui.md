# WebUI

## 连接与运行

| 页面 | 功能 |
| --- | --- |
| 连接 | 模型服务、平台账号、配置导出与合并导入 |
| MCP | 添加、编辑、删除本地命令或远程 HTTP 服务，查看状态，连接与断开 |
| Skills | 搜索已发现的 Skills，查看来源与完整内容 |
| Agent | 配置执行角色、默认模型、描述与单轮最大步骤 |
| 运行 | 默认模型、自动压缩、压缩 Token 参数、额外 Skills 路径或 URL、插件状态 |
| 投递记录 | 检查、重试和核实消息投递 |

MCP 可粘贴 `mcpServers` 或 `mcp.servers` JSON；包含多个服务时，选择一项保存。本地服务支持逐行参数、进程工作目录和环境变量，远程服务支持 URL 与请求头。已有配置中的其他原生选项会保留。OAuth 登录流程尚未接入此页面。

目录选择器用于查看各工作目录的原生能力与连接状态。连接和断开仅影响当前目录，本次运行有效；持久禁用请编辑服务的启动状态。保存和删除写入全局 OpenCode 配置，并同步已知目录；同步失败会提示重启。内置浏览器及来自其他配置源的 MCP 只提供临时连接操作。

Agent 与运行设置保存后重启服务生效。平台账号的身份与职责仍在账号设置中配置。删除 Agent 配置前需解除账号和活跃会话的使用；内置 Agent 删除本地配置后恢复原生默认值。

这些配置会随「配置迁移」导出。Skills 文件、MCP 程序及环境依赖仍需在目标机器准备。

## 会话设置

- 修改名称、模型和 Agent，查看 Token、缓存读取和模型报告的累计费用。
- 开关调试、压缩上下文、配置有序权限规则。
- 导出 OpenCode 原生会话 JSON、重置或归档。

切换 Agent 和手动压缩需要等待当前生成完成。压缩保留原会话 ID，由 OpenCode 执行，可能产生模型调用。调试开关、权限规则与其他管理操作不会作为用户消息写入上下文。

权限默认静默允许；单个会话可设为询问、拒绝或添加针对操作与资源的规则，后面的匹配规则优先。四个工具目录入口始终可用，真实工具执行仍遵循权限。会话 JSON 导出用于备份和检查，此页面尚不提供历史会话导入。
